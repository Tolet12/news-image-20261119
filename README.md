This program writes a one-image summary of 19 November 2026 world news: a newspaper front page drawn entirely in code. Its four panels show Trump, Xi and Putin at their first three-way summit in Shenzhen on the sidelines of APEC, the World Court ruling that Myanmar committed genocide against the Rohingya, Anthropic's record stock-market debut at $83 a share, and supertankers struck by mines in the Strait of Hormuz, with a ticker strip along the bottom carrying the day's other stories. The graded program (`main.py`, Python standard library only) copies the committed `entry.png` to the output directory; the image itself was drawn locally by `make_image.py` using Pillow.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
